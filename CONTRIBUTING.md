# Contributing

Contributions are welcome. This project is offered under AGPL-3.0-only and an alternative commercial license, so TreeSeed must have permission to distribute accepted contributions under both models.

By submitting a contribution, you represent that you have the right to submit it and grant the project owner a perpetual, worldwide, non-exclusive, royalty-free, irrevocable license to use, reproduce, modify, distribute, publicly perform, publicly display, sublicense, and relicense the contribution, including under the project's AGPL and commercial licenses. You retain ownership of your contribution.

Contributor authorization is completed once per GitHub account, not once per pull request. The trusted `AGPL Committer Authorization` workflow reads the provider-authenticated pull-request author login and compares it case-insensitively with `.github/approved-committers.json` from the exact base commit. It never trusts email addresses, commit author text, pull-request body claims, or agent-supplied identity.

If your username is not listed, follow [.github/COMMITTER_APPROVAL.md](.github/COMMITTER_APPROVAL.md). A maintainer reviews that one-time request and adds an accepted username through a policy pull request. After the policy reaches the target branch, future pull requests from that GitHub account require no contribution checkbox. Contributions made on behalf of an employer still require authority from that employer.

Committer approval does not bypass assignment authority, exact-head checks, tests, review, staging, main, or release policy.
